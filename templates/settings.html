💬 Prompt système

Personnalisez les instructions envoyées à l'IA avant chaque analyse. Si le champ est vide, le prompt par défaut ODIN est affiché et utilisé.

  • Le SQL, les stats et le plan d'exécution sont injectés via le template utilisateur (non modifiable ici)
  • La liste des outils est générée automatiquement selon l'onglet Outils IA
  • SCORE: / SEVERITY: / SUMMARY: doivent toujours être dans la réponse finale
  • Le prompt s'applique à tous les modes. Réinitialiser = retour au prompt ODIN par défaut
