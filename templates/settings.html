🔧 Outils IA disponibles

Sélectionnez les outils que l'agent IA peut utiliser pendant l'analyse. Les outils désactivés ne seront pas appelés, même si l'IA le demande.

💬 Prompt système

Personnalisez les instructions envoyées à l'IA avant chaque analyse. Si le champ est vide, le prompt par défaut ODIN est affiché et utilisé.

  • Le SQL, les stats et le plan d'exécution sont injectés via le template utilisateur (non modifiable ici)
  • La liste des outils est générée automatiquement selon l'onglet Outils IA
  • SCORE: / SEVERITY: / SUMMARY: doivent toujours être dans la réponse finale
  • Réinitialiser = retour au prompt natif ODIN par défaut

Jeton GitHub

Authentification du SDK officiel Copilot. Si la variable d'environnement GITHUB_TOKEN est définie sur le serveur, elle est prioritaire et ce champ est désactivé.

Comment créer ce jeton ?
  1. Le compte GitHub utilisé doit avoir un abonnement Copilot actif (individuel, ou siège assigné via une organisation/entreprise).
  2. Créer un jeton fine-grained avec votre compte personnel comme Resource owner, pas une organisation.
  3. Dans Permissions / Account, ajouter Copilot Requests. Choisir une expiration et ne pas accorder d'accès supplémentaire aux dépôts pour les analyses Oracle.
  4. Utiliser le jeton github_pat_… ici ou dans GITHUB_TOKEN. Les jetons classic ghp_… ne sont pas pris en charge. Documentation officielle.
  5. Cliquer sur Tester avant d'Enregistrer pour vérifier l'accès Copilot.
  6. Le test contrôle l'accès au catalogue via le SDK, pas la génération d'une réponse IA. Ne jamais communiquer le jeton. Les politiques Copilot de l'organisation restent applicables.
